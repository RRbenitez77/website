In Code Paths Intro to Web Development! 🎉 Web Development is a fun, collaborative process that allows your creativity to shine in many ways. In this course, I did a full stack of development tools and languages such as HTML CSS JavaScript and Python I learned fundamentals of frontend development, which focuses on the graphical user interface of a website. In later parts of the course I did backend and fullstack development.

Overview
The web is a fascinating, ever-evolving place. It's probably hard to imagine what your life would be like without the web. In this unit, you'll start interacting with the web as code. You will learn how HTML, CSS, and JavaScript work together to form the front-end design of a website by exploring and altering some websites that you may know and use.
